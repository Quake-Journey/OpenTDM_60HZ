# Исходники, авторы и лицензии

## Что лежит в репозитории

| Папка | Что это | Основа |
|---|---|---|
| `q2pro/` | движок Q2PRO; из него собирается выделенный сервер `q2proded64.exe` | форк q2trek/q2pro ревизии `dd240d1` и изменения этой сборки |
| `opentdm/` | мод OpenTDM; из него собирается `opentdm/gamex86_64.dll` | локальная копия исходников OpenTDM (см. ниже), перенос изменений q2trek/opentdm для повышенной частоты и изменения этой сборки |
| `tests/tickrate-tests/` | стенд API3: подключает настоящий код мода и движка и проверяет его на разных частотах | q2trek/tickrate-tests ревизии `cf21e40` и сценарии этой сборки |
| `tests/windows/` | сборка и запуск стенда под Windows, сравнение с исходным OpenTDM, обратные проверки | эта сборка |
| `tools/` | рецепт сборки под Windows x64 (`build_win64.py`), строки версий и хэши выпуска (`release.json`) | эта сборка |
| `config/` | пример настроек дуэльного сервера | эта сборка |
| `docs/` | документация | эта сборка |

Файлы в `q2pro/`, `opentdm/` и `tests/tickrate-tests/` — ровно те, из которых собраны и проверены файлы выпуска r6010 (внутренние ревизии `187fcd9` движка, `ade588f` мода и `55bc193` стенда; они же видны в строках версий `r6010~60hz.187fcd9` и `r6010~60hz.ade588f`).

## История в этом репозитории

Внутренняя история разработки не публикуется. Вместо неё здесь три коммита:

1. **Исходные тексты, с которых начата работа:** q2trek/q2pro `dd240d1`, q2trek/tickrate-tests `cf21e40` и локальная копия OpenTDM — игровой код без изменений, с добавленным рецептом сборки Windows x64 (Meson: curl и zlib-ng как у движка).
2. **Исходники выпуска r6010:** движок, мод и стенд в проверенном состоянии.
3. **Документация, рецепт сборки, стенд для Windows и пример настроек.**

Все изменения кода относительно исходных текстов видны как разница между первым и вторым коммитом:

```
git diff <первый коммит> <второй коммит> -- q2pro opentdm tests/tickrate-tests
```

Первый коммит нужен ещё и стенду: из него берётся исходный OpenTDM для сравнения ([tests.md](tests.md)).

## Откуда взяты исходные тексты и кто их авторы

- **Quake II** — id Software. Исходный код игры опубликован по лицензии GNU GPL v2. Данные игры (файлы `pak*.pak`: карты, модели, звуки) принадлежат id Software и здесь не распространяются.
- **Q2PRO** — улучшенный клиент и сервер Quake II; автор Andrey Nazarov (skuller) и участники проекта, https://github.com/q2pro/q2pro. Уведомления об авторских правах — в заголовках файлов `q2pro/`.
- **q2trek** — форки Q2PRO, OpenTDM и OpenFFA с поддержкой частоты сервера от 10 до 60 Гц и стенд tickrate-tests (https://github.com/q2trek); по сведениям владельца проекта, это код серверов DosZone с частотой 60 Гц. Отсюда взяты движок (`q2trek/q2pro` `dd240d1`), стенд (`q2trek/tickrate-tests` `cf21e40`) и изменения мода (`q2trek/opentdm` `c64cf55`). В мод перенесены только изменения, связанные с частотой; прочие правки q2trek/opentdm не переносились.
- **OpenTDM** — открытый мод Quake II для командных игр и дуэлей. История проекта ведётся в репозитории https://github.com/packetflinger/opentdm; в коде есть пометки автора r1ch. Основой мода в этой сборке стала локальная копия исходников OpenTDM владельца этого проекта (база его дуэльного сервера). У этой копии нет истории git; ближе всего она к ревизии `ead29b6e9` репозитория packetflinger/opentdm («skullers version as a base», 2015), но с ней не совпадает.
- **Эта сборка** (Quake-Journey): перенос изменений q2trek на локальную базу OpenTDM, шаг 100 мс для оружия, снарядов, падения, таймеров и матча, плавный показ снарядов клиентам 60 Гц, автозапись матчей MVD, диагностика ровности шагов и движения, настройки Windows для ровных шагов, рецепт сборки и стенд под Windows, документация.

## Лицензии

- `q2pro/` — GNU GPL v2 (`q2pro/LICENSE`).
- `opentdm/` — GNU GPL v2 (`opentdm/LICENSE.txt`).
- `tests/tickrate-tests/` — GNU GPL v2 (`tests/tickrate-tests/LICENSE`).
- Остальное (`tests/windows/`, `tools/`, `config/`, `docs/`) распространяется на тех же условиях GNU GPL v2 (`LICENSE` в корне).
- В собранные файлы статически встроены библиотеки **curl** 8.15.0 (лицензия curl, `licenses/curl.txt`; только в мод) и **zlib-ng** 2.2.4 (лицензия zlib, `licenses/zlib-ng.txt`), а также среда выполнения компилятора MinGW-w64 GCC. Исходники curl и zlib-ng Meson скачивает при сборке по адресам из файлов `subprojects/*.wrap` и проверяет их SHA-256.

## Внутренние пометки в исходниках

В комментариях исходников остались рабочие пометки разработки: номера доработок, даты, сокращения. Они оставлены как были, чтобы опубликованные исходники в точности совпадали с теми, из которых собраны и проверены файлы выпуска.
