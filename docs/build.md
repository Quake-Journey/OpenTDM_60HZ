# Сборка из исходников под Windows x64

Рецепт собирает ту же пару файлов, что лежит в выпуске: `q2proded64.exe` (движок) и `opentdm/gamex86_64.dll` (мод). Собирать самому не обязательно — готовые файлы есть в [Releases](https://github.com/Quake-Journey/OpenTDM_60HZ/releases/tag/r6010).

## Что нужно

- Windows 10 или 11, 64 бит.
- **MinGW-w64 GCC** для `x86_64-w64-mingw32`. Файлы выпуска собраны GCC 14.1.0 (потоки win32) с GNU Binutils 2.41; подойдёт и другая сборка MinGW-w64 GCC, но тогда файлы будут отличаться побайтно.
- **Python** 3.12 или новее.
- **Meson** и **Ninja**: `py -m pip install meson==1.10.2 ninja` (выпуск собран Meson 1.10.2 и Ninja 1.12.1).
- **Git** — чтобы получить исходники и для стенда.
- Доступ в интернет при первой сборке: Meson скачивает исходники curl 8.15.0 и zlib-ng 2.2.4 и проверяет их SHA-256 (адреса и хэши — в `q2pro/subprojects/*.wrap` и `opentdm/subprojects/*.wrap`). В репозитории эти архивы не лежат.

## Сборка

```
git clone https://github.com/Quake-Journey/OpenTDM_60HZ.git
cd OpenTDM_60HZ
git checkout r6010
py tools\build_win64.py --mingw C:\mingw64
```

`--mingw` — папка MinGW-w64, в которой лежит `bin\x86_64-w64-mingw32-gcc.exe` (вместо параметра можно задать переменную окружения `MINGW_DIR` или добавить `bin` в `PATH`). Если `ninja.exe` не в `PATH`, укажите `--ninja C:\путь\ninja.exe`. Число потоков компилятора — `--jobs` (по умолчанию 4).

Результат:

```
out\q2proded64.exe
out\opentdm\gamex86_64.dll
out\manifest.json        версии инструментов, параметры сборки, SHA-256
```

Промежуточные файлы — в `build\`. Рецепт копирует исходники в `build\src\q2pro` и `build\src\opentdm-local` и собирает их в `build\obj\engine` и `build\obj\opentdm`. Такие имена папок нужны для сверки: в собранные файлы попадает относительный путь к нескольким исходникам zlib-ng (тексты проверок), и с этой раскладкой он такой же, как у файлов выпуска.

Строки версий (`r6010~60hz.187fcd9`, `r6010~60hz.ade588f`) берутся из `tools/release.json`. Если вы меняете исходники, поменяйте и строки версий, чтобы ваша сборка не выдавала себя за выпуск.

Время сборки, которое компилятор записывает в файлы (дата в строке версии и в `gamedate`, дата и время в тексте отчёта о сбое движка), рецепт по умолчанию берёт тоже из `tools/release.json` — это записанное время сборки выпуска, `Nov 18 2026, 17:07:41` (переменная `SOURCE_DATE_EPOCH`). Так эти тексты совпадают с файлами выпуска в любой день. Чтобы записать текущее время, добавьте `--build-time now`.

## Параметры сборки

Движок (`q2pro`): `buildtype=release`, `variable-fps=true` (частота мира выше 10 Гц), `packetdup-hack=true` (команда игрока `packetdup`), `mvd-server=true` (демки MVD и GTV), `zlib=enabled`, `game-new-api=false` (мод использует обычный API игры), статическая компоновка; клиентские библиотеки (картинки, звук, curl, SDL) выключены — выделенному серверу они не нужны.

Мод (`opentdm`): `buildtype=release`, `optimization=2`; curl и zlib-ng собираются из исходников и встраиваются статически. В `meson.build` мода запрещена быстрая математика (`-fno-fast-math`): расчёты времени и физики должны совпадать на всех частотах.

Полный список — в `ENGINE_OPTS` и `GAME_OPTS` файла `tools/build_win64.py`.

## Сверка с файлами выпуска

SHA-256 файлов выпуска записаны в `tools/release.json`, и рецепт сравнивает с ними результат. Совпадения SHA-256 ждать не стоит: в заголовок каждого файла Windows (PE) компоновщик записывает момент компоновки, а от него зависит и контрольная сумма заголовка. Чтобы сравнить всё остальное, распакуйте архив выпуска и укажите его папку:

```
py tools\build_win64.py --mingw C:\mingw64 --compare-with C:\путь\к\распакованному\архиву
```

Рецепт сравнит файлы побайтно и назовёт поля, в которых они расходятся.

**Проверено на чистой выгрузке этого репозитория** (18.11.2026; MinGW-w64 GCC 14.1.0, GNU Binutils 2.41, Meson 1.10.2, Ninja 1.12.1, Python 3.14): оба собранных файла совпали с файлами выпуска во всех байтах, кроме времени компоновки в заголовке PE (у мода — ещё и в таблице экспорта) и контрольной суммы PE. Поэтому их SHA-256 отличаются от SHA-256 выпуска, а всё остальное — код, данные, строки версий и времени сборки — то же.

## Linux

Сборка под Linux для этого выпуска не делалась и не проверялась. Исходники движка и мода её поддерживают (Meson), но рецепт `build_win64.py` рассчитан только на Windows x64.
