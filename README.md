# OpenTDM 60 Гц — сервер Quake II для дуэлей

Выделенный сервер Quake II для Windows x64: движок Q2PRO и мод OpenTDM, мир которых считается 60 раз в секунду (`sv_fps 60`). У игроков с поддержкой 60 Гц движение, лифты и полёт снарядов идут плавно, а стрельба, попадания, рокетджамп, урон от падения, таймеры предметов и матча работают так же, как на обычном сервере 10 Гц.

Сервер рассчитан на дуэли 1 на 1 и проверен на карте `q2dm1`. Текущий выпуск — **r6010**.

## Скачать

Готовая сборка — в разделе [Releases](https://github.com/Quake-Journey/OpenTDM_60HZ/releases/tag/r6010): архив `OpenTDM_60HZ-r6010-win64.zip`. Его SHA-256 указан в описании выпуска и в файле `SHA256SUMS` рядом с архивом.

| Файл в архиве | Что это |
|---|---|
| `q2proded64.exe` | выделенный сервер (движок Q2PRO), 64 бит |
| `opentdm/gamex86_64.dll` | мод OpenTDM, 64 бит |
| `opentdm/opentdm-60hz.example.cfg` | пример настроек дуэльного сервера |
| `OpenTDM_60HZ/` | инструкция, описание перехода, известные проблемы, лицензии, контрольные суммы |

## Что нужно отдельно

- **Данные Quake II.** Файлы `pak*.pak` из папки `baseq2` вашей копии игры: `pak0.pak`, а также `pak1.pak` и `pak2.pak` из официальных обновлений — карты `q2dm1`–`q2dm8` лежат в `pak1.pak`. Игровые данные не входят в архив и не распространяются.
- **Windows x64**: Windows 10, 11 или Windows Server 64 бит.
- Свободный порт UDP (обычно 27910).

60 снимков в секунду получают клиенты, которые умеют запрашивать точную частоту (Q2PRO-X с включённой адаптацией, клиенты на основе q2trek/q2pro). Остальные по устройству движка получают 10 (или 20) снимков в секунду и видят игру как на обычном сервере; из таких клиентов в сети проверен только Q2PRO-X без адаптации — см. [известные проблемы](docs/known-issues.md).

## Чистый запуск на q2dm1

1. Создайте папку сервера (например, `C:\q2server`) и скопируйте в `C:\q2server\baseq2` файлы `pak*.pak` из папки `baseq2` вашей копии Quake II.
2. Распакуйте в эту же папку архив выпуска.
3. Скопируйте `opentdm\opentdm-60hz.example.cfg` в `opentdm\server.cfg`, задайте имя сервера и свои пароли.
4. Запустите из этой папки:

   ```
   q2proded64.exe +set game opentdm +set net_port 27910 +exec server.cfg
   ```

5. В консоли сервера команда `sv_fps` должна показать 60, `status` — карту `q2dm1`.

Подробнее, а также обновление работающего сервера и откат: [docs/install.md](docs/install.md).
